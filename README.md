# STBM: Qwen2.5 Omni speech diarization and recognition

This release contains the STBM model implementation and the Auden library it uses.

- [Model README: setup, training, inference, and evaluation](examples/tagspeech/README.md)
- [License](LICENSE)
- [Third-party notices](NOTICE)

Install from this directory with `pip install -e .`, then follow the model README to configure local model and dataset paths.

This implementation builds on [TagSpeech and Auden](https://github.com/AudenAI/Auden). The model README includes the TagSpeech citation.
